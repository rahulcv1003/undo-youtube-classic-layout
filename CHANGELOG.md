# Changelog

All versions below are development builds. No Chrome Web Store release is claimed.

## 0.1.4 — 2026-10-14

- Prepared GitHub bug, feature-request and support-question forms.
- Added architecture, development notes, documentation index, support guide, roadmap and publication runbook.
- Excluded local briefs, live browser captures and key/environment files from publication candidates.
- Connected reviewed diagnostics and the homepage link to the owner's public repository. Automatic selector downloads and other external destinations remain disabled.

## 0.1.3 — 2026-10-14

- Added a guarded native theater-mode compatibility bridge.
- Added a missing native miniplayer button, supporting nested player controls without cloning video or duplicating a visible native control.
- Synchronized accessible mode labels with watch-page state and clean up owned controls on disable.
- Recorded live development-code evidence and installed-build/fullscreen validation limits.
- Verified 71 unit tests and 16 isolated browser integration tests locally.

## 0.1.2 — 2026-10-14

- Refined popup and options hierarchy, switches, neutral palette and status presentation.
- Added light/dark UI snapshots and automated accessibility checks.
- Retained 0.1.1 restoration and navigation behaviour.

## 0.1.1 — 2026-10-14

- Replaced a starvation-prone debounce with animation-frame scheduling and a bounded fallback.
- Added slow-root discovery, root-replacement recovery and reused-renderer repair.
- Preserved restoration during video navigation and added a bounded startup guard and back-forward recovery.

## 0.1.0 — 2026-10-14

- Initial MV3 implementation with structural detection and reversible native renderer restoration.
- Added settings, optional AI hiding/spoiler shield/wide-screen controls, local UI and privacy-safe diagnostics.
- Added strict selector validation, dormant remote-update support, tests and packaging checks.
